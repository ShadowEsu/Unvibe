## Problems discovered

### Fixed
1. **Event listener memory leak** (`app/src/preload/preload.ts`): 5/8 IPC
   listeners returned `IpcRenderer` instead of a cleanup function. When React
   components mount/unmount, listeners accumulate. Fixed all 5 to return
   `() => ipcRenderer.removeListener()`. Verified: typecheck, 31 tests, build.

### Not fixed (low-risk, documented)
2. **macOS-specific `firstName()` call** (`main.ts:87-93`): `id -F` is
   macOS-only. Falls back to `process.env.USER` on other platforms.
3. **Timer leak on widget close** (`main.ts:591-601`): `resizeTick` interval
   not cleared if widget closed during active resize (guarded, runs one extra
   iteration at most).
4. **`settings.ts:144-148` silent persist failure**: Filesystem write errors
   are silently caught — settings changes could be lost.
5. **`backend.ts:48-53` empty auth header**: When not trial/full-product build,
   sends `authorization: Bearer ` with trailing space.
