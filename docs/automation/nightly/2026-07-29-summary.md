## Known audit issues (carried forward, newly verified)

### Backend (web/)
- **`redeemDeviceCode` return type mismatch**: Interface declares `'used' | 'expired'`, but neither MemoryStore nor SupabaseStore returns them — they return `'pending'` or `'unknown'`. Tests that expect `'used'`/`'expired'` will always fail.
- **MemoryStore has no session/device-code expiry**: Tokens live forever. No time-based eviction. The `security.test.ts` expiry tests cannot pass.
- **No server-side rate limiting** on any API route.
- **No prompt versioning**: Server and local prompts diverge; no version field in `ReviewRequestPayload`.
- **Model defaults** (`claude-sonnet-5`, `gemini-3.1-flash-lite`) reference future/fictional model names.
- **No retry/backoff** on upstream AI API failures.

### Desktop overlay (app/)
- **Preload listener leak**: `onReviewEvent` and `onAutocollapse` (`preload.ts:55-56`) use `ipcRenderer.on` without returning unsubscribe functions, unlike `onBarNotify` which correctly returns one.
- **Widget IPC listener leak**: `widget.tsx:271` `useEffect` registers listeners with no cleanup; listeners accumulate if component remounts.
- **`Icon` component** (`companion.tsx:144`): SVG rendered without `aria-hidden="true"` — screen readers parse SVG path data.
- **Settings modal**: No `Escape`-to-close handler (backdrop click only).
- **macOS path hardcoded** in `backend.ts:19` (`~/Library/Application Support/Unvibe/.env`) — no Linux fallback.
- **macOS-specific behavior** (selection capture via `osascript`, Dock icon, tray, accessibility permissions) — **unverified on Linux runner**.
