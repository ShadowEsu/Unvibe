## Problems discovered and fixed

1. **`web` test fixtures were stale** (broke typecheck + 5 tests): tests referenced removed
   `priceFor`/`*SavingsPercent` exports and a `SESSION_TTL_MS`/clock API that no longer existed.
   Fixed fixtures and tests to match the current plans/entitlements and store APIs.
2. **`MemoryStore` did not honor its own `Store` interface**: never enforced device-code or token
   expiry (declared `'expired'`/`'used'` returns), no clock injection. Now matches the documented
   contract and the Supabase migrations (`expires_at` semantics).
3. **History pagination drift (sync data-loss risk)**: both stores used a positional offset cursor
   over a full sorted snapshot, so a record written mid-pull was skipped, silently missing from the
   local mirror. Switched to keyset pagination via the existing `pagination.ts` helpers
   (`(ts, id)`), and `SupabaseStore` now calls the `history_page` RPC from migration 0007 (which was
   previously unused, and no longer scans the full table per page).
