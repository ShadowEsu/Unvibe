## Problems discovered

### Fixed: shortcut rendered differently on every surface
- **Root cause**: three ad-hoc accelerator formatters drifted apart — `bar.tsx:27` (`prettyShortcut`), `widget.tsx:78` (`prettyAccel`), `companion.tsx:170` (`prettyAccel`). Same `settings.shortcut` displayed as `⌘U` (bar), `⌘+U` (widget), `⌘U` (companion); the bar formatter also left a bare `Control` modifier unrendered (`Control+⇧K` on non-Apple).
- **Fix**: new `app/src/core/accelerator.ts` `formatAccelerator()` — one canonical formatter used by all three surfaces. Added `app/test/accelerator.test.ts` (5 regression tests).
- **Result**: `app/` 36/36 tests pass (was 31), typecheck clean, build ok.

### Verified, no change needed
- Preload bridge exposes no network/node to renderers; all I/O stays in the main process.
- Backend keys/tokens only exist in main process storage (safeStorage-encrypted); renderer sees only `{ userId, email }`.
- Widget resize geometry (`applyWidgetResize`, `clampToVisibleArea`) is min/max guarded; no off-screen case found.
- `settings:set` IPC restores the previous shortcut and re-registers it when a new one fails.
