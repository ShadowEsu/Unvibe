## Problems discovered

### web/ test files out of sync with source (8 typecheck errors, 5 test failures)

**Root cause:** The test suite at `web/test/billing.test.ts` and `web/test/security.test.ts` referenced exports and function signatures that either did not exist or had changed in the source files `web/src/billing/plans.ts` and `web/src/data/memoryStore.ts`.

**Specific issues fixed:**

1. **Missing pricing functions** (`web/src/billing/plans.ts`):
   - Added `priceFor(plan, interval, seats)` — returns price in cents
   - Added `proAnnualSavingsPercent()` / `teamsAnnualSavingsPercent()` — returns 25
   - Added Teams seat validation to `normalizedSeats`: throws on non-integer or <2 seats

2. **Missing session/device expiry** (`web/src/data/memoryStore.ts`):
   - Added `SESSION_TTL_MS = 30 * 60 * 1000`
   - Made constructor accept optional `now: () => number` (default `Date.now`) — follows `MemoryBillingStore` pattern
   - `redeemDeviceCode` now returns `'expired'` for codes older than 10 min, `'used'` for already-redeemed codes
   - `approveDeviceCode` is idempotent (returns existing token) and rejects expired codes
   - `userForToken` expires sessions after `SESSION_TTL_MS`
   - Token creation timestamps stored alongside userId
   - Fixed `deleteAccount` to destructure the new token record format

3. **Test alignment** (`web/test/billing.test.ts`):
   - Fixed `planLimit` calls to pass `seats` as 3rd argument
   - Added regression test validating internal pricing consistency across all plan/interval/seat combinations

4. **Tests now passing**:
   - "pricing math matches every published total" — was failing (no `priceFor`)
   - "Teams rejects abusive seat quantities" — was failing (no throw in `normalizedSeats`)
   - "duplicate device approval is idempotent" — was failing (no idempotency or 'used' state)
   - "expired device codes cannot be approved or redeemed" — was failing (no expiry check)
   - "opaque sessions expire server-side" — was failing (no SESSION_TTL_MS)
