## Static Inspection Findings

### Backend & Auth (web/)
- **No credentials reach renderer code** ✅ Architecture enforced via CSP, preload bridge, and IPC
- **Retry/backoff/idempotency**: Present in `sync.ts`, `backend.ts`, `syncModel.ts`. Webhook dedup via `claimWebhook()`
- **No `Retry-After` header**: Server returns 429 but doesn't set the header; client uses own exponential backoff
- **PII exposure**: Email is the only PII; gated behind auth and RLS
- **Notable edge cases**: `MemoryStore.redeemDeviceCode` had no expiry (fixed); `SupabaseStore.deleteAccount` not wrapped in transaction; sign-in endpoint lacks rate limiting

### Desktop Overlay (app/)
- **59 IPC channels**: `widgetOf(e)` pattern used inconsistently — several channels skip sender validation
- **Preload bridge**: Well-scoped — no dangerous APIs exposed. CSP blocks renderer network calls
- **Window geometries**: Widget bounds persisted in `unvibe-settings.json`. Bar/companion positions ephemeral
- **macOS code**: Entire `selection.ts` is macOS-only (osascript). Guarded but no Linux fallback. Other macOS code properly guarded with `isMac` checks
- **Error boundaries**: Zero React Error Boundaries across all three renderers
- **Accessibility**: ~63 ARIA attributes but gaps in focus trapping, aria-expanded, keyboard navigation in tablists

### AI Learning Engine (app/src/core/ + web/src/ai/)
- **5 explanation levels** (New/Beginner/Intermediate/Advanced/Expert) with per-level prompt guidance
- **Comprehension questions** generated by LLM with structured JSON output parsing
- **No hardcoded mastery percentages** — skill states computed from integer evidence counts
- **Secret filter**: Scans code context for tokens, API keys, private keys, high-entropy strings before any network request
- **Streaming**: SSE pipeline with `SseParser` on client side, supports Anthropic/Gemini/OpenAI-compatible providers
