# Unvibe Night Lab — RETIRED

This skill and its GitHub Actions workflow are **retired**. Scheduled OpenCode night runs produced a large volume of unmerged `opencode/nightly-*` branches and failing scheduled jobs without reliable product value.

**Do not** create `opencode/nightly-*` branches, open night-lab PRs, or re-enable a cron for this skill unless the founder explicitly reinstates a new, narrower automation with a clear merge and prune policy.

Historical mission names (for archaeology only): repository-health, backend-and-sync, desktop-overlay, ai-learning-engine, competitor-research-and-v2, product-design-and-accessibility, integration-review-and-morning-summary.

Prefer human-directed work, the personal exec-team skills, and targeted CI (`verify:beta`) instead of overnight autonomous PR farms.
