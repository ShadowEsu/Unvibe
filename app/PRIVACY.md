# Unvibe Privacy Policy

**Last updated: October 2026**

## What Unvibe processes

Unvibe is a desktop application that helps you understand code. When you select code and activate Unvibe, the following may be sent to our AI provider:

- The exact code snippet you selected
- The file name and line range
- Your chosen explanation depth
- The programming language detected
- Questions and Chat messages you type
- On Pro, parts of nearby files from the same project, so an explanation can follow what the code calls
- For Change Briefs and diff explanations, the git diff you chose

## What Unvibe does NOT do

- Unvibe never sends your entire repository, and sends project files only as described above
- Unvibe never reads your screen or records your keystrokes outside of intentional selections
- Unvibe never runs arbitrary code, executes commands, or modifies your files
- Unvibe does not build its own model-training dataset from your code

## On-device secret filtering

Code selections, follow-up questions, and Chat messages are scanned for API keys, tokens, private keys, passwords, and connection strings **before** any data leaves your Mac. Known credential formats and password-style assignments block the request, and nothing is sent. If an explanation request only contains a string that looks random, you are shown what was found, and nothing is sent unless you choose Send anyway. Chat and lesson questions have no Send anyway step: a message with any finding is not sent. The filter catches common keys and tokens, but no filter can promise to find every sensitive value.

## Account and sync

When you create an account, your learning history (reviews, concepts, streaks) is synced across your devices via Supabase. This data includes:

- Review timestamps and outcomes
- Concepts encountered and understood
- Streak and progress metrics

You can see your saved explanations and progress in the app at any time. The app has no export button yet; for a copy of your data, email **hello@unvibe.site**. To delete it, see Data deletion below.

## Without an account

Without an account, the app sends a random install ID, your computer's system (Mac or Windows) and the app version with each cloud explanation and with the usage check it makes when it starts, so the free explanations can be counted. Under a hashed form of that ID, the server stores:

- When the app first started, and the system and version it started on (stored once, never updated)
- How many explanations it has used
- When it first explained the setup sample, first explained your own code, and first explained code again on a later day of its first week

No code or prompts are stored with it. Signed in, explanations carry your sign-in token instead of the install ID.

## Anonymous setup progress

The app also sends one message per setup step, the first time it happens: setup finished, Accessibility asked for and allowed (Mac only), signed in, the explanation level question answered, and the question about opening Unvibe when you log in shown and answered yes. Each message carries the step name with the same random install ID, system and app version, never your sign-in token. The server keeps only the step and the time it arrived (for signing in, only the day), never your code, file names, email or IP address. A step that does not get through is sent again on a later launch.

To turn this off, open Settings › Privacy & Data and switch off **Send anonymous setup progress**. That switch does not cover the install ID, dates and counts under Without an account, which come with requests the app makes anyway.

## Feedback

When you send feedback from the app or the website, Unvibe stores your star rating and message, where it came from (the app version or the page), and your email only if you add it. Your IP address is used only in the server's memory, to stop repeated sends, and is not stored with your feedback. Each send is also counted as one PostHog event that carries only the star rating and where it came from, under a random ID that is new each time.

## Third-party services

AI explanations and Chat replies are generated by the Google Gemini API. No code or text you write is sent without your explicit action (requesting an explanation, asking a question, or sending a Chat message). Google's Gemini API terms decide whether Google may use the content. If you add your own provider key in the app, requests go to that provider under its terms instead.

Authentication and data sync are powered by Supabase. Supabase provides the database and auth infrastructure.

## Data deletion

Signed in, you can delete your account and all associated data at any time from Settings › Account & Plan › Delete account. If a paid subscription is still active, cancel it in Manage billing first. Deletion removes:

- All learning events and reviews
- Account credentials and session tokens
- Synced data on our servers
- On this computer: your learning, the API key you saved in Unvibe, and the name, email and last project folder saved in Unvibe

Without an account, **Erase learning** in Settings › Account & Plan removes every saved explanation from this computer.
